02 / The group chat, summarized

Our shared view on AI and the future of software engineering

Five perspectives, one strong review culture. Nobody gave the bot production access.

Where we agree / human judgment stays on call

  • AI makes coding faster: useful for boilerplate, first drafts, tests, refactoring, finding bugs and exploring possible solutions.
  • Its output is a draft, not a verdict. It can invent APIs, make mistakes that are easy to miss, or offer a perfectly formatted guess.
  • Developers remain responsible for testing, reviewing and understanding the result. Human judgment is what checks that it is correct, reliable and solves the real problem.
  • Over the next 5–10 years, we expect more time spent specifying, planning, guiding agents and verifying their work—and less time writing every line from scratch.

Where the emphasis differs / same destination, different route

  • Aryan calls out system design, clear specifications, testing and observability; Rachana stresses problem-solving and keeping coding knowledge sharp.
  • Cemon puts clear requirements and prompt engineering front and center as AI takes on most coding tasks.
  • Shrividya imagines agents handling bigger jobs—including testing and bug fixes—while fundamentals help us catch their mistakes.
  • Srajan adds explainability to the core skills: if we cannot explain an AI's choice, it is still a guess.
“AI won't replace developers who write tests. It will replace the ones who never read the code it writes.”— Aryan / hot take
“AI can write a thousand lines of code in seconds, but finding the one tiny mistake that breaks everything is a different story.”— Rachana / hot take
“An AI you can’t explain is just a very expensive guess with good formatting.”— Srajan / hot take
“Software engineers spend time and take responsibility for testing the code which they didn't write.”— Cemon / hot take
“AI can write the code, but it cannot take responsibility when the system breaks at 3 AM!”— Shrividya / hot take
TEAM RULE: ship the assist, keep the accountability.— Group 14 / release checklist

Forecast / 5–10 years

Less typing. More thinking. Still read the diff.

Our shared bet: software engineers will spend more time shaping the problem, checking the system and making decisions. AI may become a normal teammate; knowing the basics is how we know when that teammate is confidently wrong.
