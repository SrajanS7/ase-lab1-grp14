## What I think about AI in software engineering today

AI has made software development faster and easier, but it hasn't made developers less responsible. It can help us write code, find bugs and solve problems, but it can also make mistakes that are easy to miss. I think AI is a great teammate, as long as we don't let it do all the thinking for us.

## Where software engineering will be in 5–10 years

I think AI agents will become a normal part of software development. They will be able to handle bigger tasks, from writing code to testing and fixing bugs. Developers will spend more time planning, making decisions and checking the results. But understanding the basics will always matter, because someone still needs to know when the AI gets things wrong.

## My hot take on AI

AI can write the code, but it cannot take responsibility when the system breaks at 3 AM!
