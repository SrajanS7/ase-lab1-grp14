## What I think about AI in software engineering today
Great at boilerplate, refactoring and writing the first version of a test. But in production it happily invents an API that doesn't exist and sounds completely sure about it. It speeds up good engineers and hides mistakes from careless ones.

## Where software engineering will be in 5–10 years
Engineers will write less code and spend more time defining the task, designing the system and reviewing what agents produce. Testing, observability and clear specifications will matter more than typing speed.

## My hot take on AI
AI won't replace developers who write tests. It will replace the ones who never read the code it writes.
